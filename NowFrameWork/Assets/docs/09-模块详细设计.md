## 1. C11 本地化

### 1.1 目标与非目标

目标：

- 运行期切换语言，不重启、不重建界面；
- 文本、字体、图集、语音随语言一起切换；
- 缺失数据有确定行为（占位 + 日志 + 编辑器校验），不出现空白或乱码。

非目标（首版不做，留扩展点）：

- 不做翻译管理平台（TMS）与协作审校流程；
- 不做 RTL（阿拉伯语/希伯来语）排版；
- 不做复数、性别、量词的语法变体（以参数化 + 分词规避）；
- 不做语音本地化（资源变体预留目录）。

### 1.2 支持语言与回退链

| 枚举 | BCP-47 | 资源变体标签 |
|---|---|---|
| `ZhHans` | `zh-Hans` | `lang_zh_hans` |
| `ZhHant` | `zh-Hant` | `lang_zh_hant` |
| `En` | `en` | `lang_en` |
| `Ja` | `ja` | `lang_ja` |
| `Ko` | `ko` | `lang_ko` |

- 首版交付范围：**中（简）+ 英** 两种；其余枚举保留，按项目启用；
- 系统语言映射：`Application.systemLanguage` → 枚举；`ChineseSimplified` → `ZhHans`，`ChineseTraditional` → `ZhHant`，其余映射到 `En`；
- 默认语言：项目配置项 `DefaultLanguage`（默认 `ZhHans`），无保存值且系统语言不支持时使用；
- 回退链：`请求语言 → 语言族（zh）→ DefaultLanguage → En`；逐级找 Key，仍缺失才显示占位。

### 1.3 文本表 schema

源表 `CFG_Localization`（与 C10 同一导出管线）：

| 列 | 类型 | 规则 |
|---|---|---|
| `Key` | string | 唯一；`模块.对象.语义`，如 `ui.settings.title`、`item.1001.name` |
| `ZhHans` / `En` / … | string | 允许空（空则走回退链） |
| `ParamCount` | int | 占位符个数，导出时校验与文本一致 |
| `MaxLen` | int | 目标语言下的长度上限，UI 校验用 |
| `Note` | string | 给翻译/策划的注释，不进包 |

规则：

- Key 一旦发布不得改名（等于资源 ID），改名走新增 + 旧 Key 保留一个版本；
- 占位符统一 `{0}` `{1}` `{name}`，禁止在文本里混入 TMP 富文本标签做样式（样式由界面控制）；
- 导出产物：二进制表 + 强类型访问器（`LocalizationTable.Get(key)`），由 C10 统一管理；
- 导出时校验：Key 唯一、ParamCount 匹配、每语言至少一门非空、Key 格式合法。

### 1.4 资源变体

| 资源 | 变体方式 | 说明 |
|---|---|---|
| 字体 | `TMP_Font_<lang>.asset` + `TMP_Font_<lang>_Fallback` | 中文子集 + 缺字回退到默认字体 |
| 图集 | Addressables Variant `lang_*` | 仅含本地化图片（logo、说明图）时使用 |
| 语音 | `A_VO_<lang>/` 分组（预留） | 首版不启用 |
| 文本表 | `Localization/<lang>` 组 | Remote，可随补丁更新 |

变体选择由 `ILocalizationService.CurrentVariantLabel` 提供给 F01，业务不直接拼路径。

> **v0.3 实现约定**：首版中英双语**不用 Addressables Variant**，改成"分组 + label"（`Localization/<lang>` 分组 + `lang_zh_hans` / `lang_en` label）。原因：Variant 会给每个变体各出一份 bundle，与 content update 组合时容易错配（见 [05 §6 R14](05-技术方案-Addressables与HybridCLR.md)）。`CurrentVariantLabel` 保留，作为 label 选择器。

### 1.5 运行时流程

**启动**（位于启动时序第 8 步，UI 之前）：

1. `F07` 读取保存的语言；没有则用系统语言映射；
2. 通过 `C10` 加载该语言表（缺失则回退默认语言表）；
3. 通过 `F01` 加载字体资产与 fallback 链；
4. 发布初始 `LanguageChangedEvent`（此时无界面订阅，用于日志与自检）。

**切换** `SetLanguageAsync(lang)`：

1. 串行锁：进行中的切换先取消（`CancellationToken`）；
2. 加载新语言表与新字体（期间保持旧语言可用，避免白屏）；
3. 更新 `Current` 与变体标签；
4. 持久化到 `F07`；
5. 发布 `LanguageChangedEvent`；
6. UI 刷新：已打开的 `UIView` 调 `OnLanguageChanged()`，`LocalizedText` 自动重取文本；
7. 释放旧字体/旧表句柄（引用计数归零才真正卸载）；
8. 记录日志：语言、耗时、字体加载耗时。

切换期间允许显示遮罩（由界面决定），但不得阻塞输入线程。

### 1.6 UI 刷新契约

- 提供 `LocalizedText : MonoBehaviour`：字段 `key` + `args`，绑定 `TMP_Text`，订阅 `LanguageChangedEvent` 自动刷新；
- `UIView` 增加虚方法 `OnLanguageChanged()`，默认实现只刷新本界面内的 `LocalizedText`；
- **禁止**在 `OnLanguageChanged` 里重建界面或重载资源（只允许改文本、字体、布局）；
- 列表：`UIList.RefreshVisible()` 只刷新可见项，不整表重建；
- 未打开的界面不刷新，打开时按当前语言渲染（天然正确）。

### 1.7 格式化与排版

- 数字/日期使用**显式格式**（`0.##`、`yyyy-MM-dd HH:mm`），不依赖 `CultureInfo`（IL2CPP 裁剪 + 区域差异不可控）；
- 长文本：按 `MaxLen` 在编辑器校验，预制体按 1.2 倍预留（德语/俄语偏长）；
- 换行：中文按字、西文按词，使用 TMP 默认换行，禁止在文本表里写死 `\n`（除非是固定排版）；
- 富文本：允许 TMP 标签，但语言无关的样式必须放在界面侧。

### 1.8 错误与降级

| 场景 | 行为 | 日志级别 |
|---|---|---|
| Key 不存在 | 返回 `[key]` 占位 | Warning（Editor 下 Error） |
| 该语言值为空 | 走回退链，最终仍空则占位 | Warning |
| 语言表缺失/损坏 | 用 DefaultLanguage 表启动 | Error |
| 字体资产缺失 | 回退 TMP 默认字体 | Error |
| 字体缺字 | TMP 显示方块；编辑器工具扫描并告警 | Warning |
| 切换失败 | 保持原语言，Toast 提示，句柄回滚 | Error |
| 并发切换 | 后一次取消前一次，只保留最后一次 | Info |

### 1.9 测试

单元（EditMode）：

- 回退链（请求语言缺失 → 族 → 默认 → En）；
- 占位符解析与 `ParamCount` 校验；
- 缺 Key 返回占位且只告警一次；
- 表校验：重复 Key、空 Key、非法格式。

集成（PlayMode）：

- 切换后已打开界面的文本与字体都变化；
- 切换后重启进程，语言保持；
- 切换期间资源句柄正确释放（泄漏快照为空）。

性能与边界：

- 表加载 ≤ 50 ms，切换总耗时 ≤ 500 ms，内存增量 ≤ 20 MB；
- 中英长文本不溢出、不截断；CJK 缺字可定位。

### 1.10 工作量与里程碑

| 项 | 人日 |
|---|---|
| 表结构 + 导出 + 校验 | 1.0 |
| 运行时（Get/Format/回退/事件） | 0.5 |
| 切换流程 + 字体/变体 + UI 刷新 | 0.5 |
| 测试与编辑器校验工具 | 0.5 |
| **合计（中英双语）** | **2.5** |

- 当前 M3 的 T3.5 按 3 人日（C11 2 + F09 1）预留，与上表基本吻合；骨架版（表 + Get + 切换事件，无字体变体）1 人日可先行；
- 每增加一种语言 +0.5 人日（字体资产另计），多语言版本不纳入 M3 承诺。
