# 36 · 框架漫游演示

> 目标：一个场景、一个入口，把框架的公共能力按顺序跑一遍，屏幕上逐条显示结果。
> 适合第一次接触框架的人"看效果"，也适合改动框架后做人工冒烟。

## 1 生成与运行

```
菜单：NowFrameWork → Tests → 创建框架漫游演示场景
场景：Assets/Scenes/FrameworkTour.scene
```

场景只有一个根物体 `Framework Tour`，挂 `BootFlow` + `FrameworkTourSample`，`BootFlow.Project Entry` 已指向演示入口。

Play 后左上角列表逐步出现：

```
OK   日志
OK   设置
OK   配置
...
```

失败步骤显示 `FAIL <步骤>：<原因>`，不影响后续步骤继续执行。

## 3 复用与未包含项

场景复用 UI 样例的预制体：`Assets/Tests/UIWindows/UiRoot.prefab`、`Window.prefab`（地址 `UiWindows/Window`），生成菜单会自动创建 EventSystem 并登记地址。

| 能力 | 原因 | 去哪里看 |
|---|---|---|
| UI 页面/弹窗 | 已包含基础流程；更完整的页面历史与缓存见独立样例 | `UIWindows.scene`、[29 导航规范](29-UI多窗口导航与Canvas规范.md) |
| 本地化 | 在独立程序集 `NowFrameWork.Localization.Sample`，反向引用 Game 会循环 | `UILocalization.scene`、[17 本地化](../06-模块API/17-本地化.md) |

## 4 扩展方式

在 `FrameworkTourSample` 里加一个 `Step` 即可：

```csharp
await Step("我的能力", async c =>
{
    // 调用框架 API；抛异常会被记录为 FAIL，不中断后续步骤
    await UniTask.CompletedTask;
}, ct);
```

约定：每个步骤自己申请、自己释放；失败时保留可重试的字段，不要静默吞掉。
