# 37 · UI 运行时装配与面板注册

> 更新：2026-11-28。适用于 `com.now.nowframework.ui.ugui` 当前实现。
> 目标：Boot 自动装配 UI，项目入口只绑定，业务只调用 `GameEntry`。

## 1 启动时序

```
BootFlow.Run
  → App.StartupAsync（Assets / Audio 等模块）
  → [UI] 如果 BootFlow 配置了 UiCatalog：
        自动创建 EventSystem（缺省时）
        自动创建 UiRoot（未提供预制体时）
        创建并启动 UiModule
  → Config / Scene / Entry
  → Running
停止：入口 ExitAsync → 关闭 UI → 资源与模块清理
```

UI 的创建由 Boot 负责，项目入口不再 `new UiModule`，也不再需要传 `_catalog`。

## 2 五步接入

| 步骤 | 操作 |
|---|---|
| 1 | 面板 Prefab 根节点挂 `UiView` 派生脚本（可用生成器自动挂） |
| 2 | 同一根节点挂 `UiPanelDefinition`，填 `PanelId` 与行为 |
| 3 | 面板登记为 Addressable（地址任意，收集器会读取） |
| 4 | 菜单 **NowFrameWork → UI → 收集面板定义**，生成 `Assets/NowFrameWork/UI/UiCatalog.asset` |
| 5 | `BootFlow` 的 **UiCatalog** 指向它；`Project Entry` 填自己的入口 |

入口代码：

```csharp
public sealed class MyEntry : MonoBehaviour, IBootEntry
{
    GameEntry.Binding _binding;

    public UniTask EnterAsync(BootContext context, CancellationToken ct)
    {
        _binding = GameEntry.Bind(context);   // UI 已由 Boot 准备好
        return UniTask.CompletedTask;
    }

    public UniTask ExitAsync()
    {
        _binding?.BeginStopping();
        _binding?.Dispose();
        _binding = null;
        return UniTask.CompletedTask;
    }
}
```

业务调用：

```csharp
await GameEntry.OpenPanelAsync(10, new MyArgs(), ct);
await GameEntry.ClosePanelAsync(10);                 // 关最上层一个
await GameEntry.ClosePanelAsync(10, all: true);      // 关全部实例
```

## 3 UiPanelDefinition 字段

| 字段 | 含义 | 说明 |
|---|---|---|
| `PanelId` | 逻辑面板 ID | 全工程唯一，`0` 视为未填写 |
| `Layer` | Page / Popup / Toast | 决定排序与返回处理 |
| `Modal` | 是否模态 | 仅允许 Popup 层 |
| `CloseOnBackdrop` | 点遮罩关闭 | 仅在 Modal 时有效 |
| `BackBehavior` | 返回键行为 | Close / Block / Ignore |
| `CacheOnClose` | 关闭后缓存 | 命中缓存时复用实例 |
| `MultiInstance` | 允许多实例 | 同一 ID 可同时打开多个会话 |

约束：

- 只能挂在 Prefab **根节点**，子节点上的会被忽略；
- `PanelId` 由人工填写，收集器校验重复与缺失；
- 同一 Prefab 承担两种逻辑（页面/弹窗）时，注册两条不同 ID 的定义，地址相同即可。

## 4 收集与校验

| 菜单 | 行为 |
|---|---|
| **收集面板定义** | 扫描 `Assets` 下所有 Prefab，校验后写入 UiCatalog |
| **校验面板定义** | 只校验，不写文件 |

校验项：

- `PanelId <= 0`
- ID 重复、Prefab 名重复
- 未登记 Addressable 或地址为空
- 根节点没有 `UiView`
- `Modal` 不在 Popup 层
- `CloseOnBackdrop` 但非 Modal

有任何错误时**不写 Catalog**，避免半套定义进入运行时。

## 5 运行时自动创建

| 对象 | 何时创建 | 归属 |
|---|---|---|
| EventSystem | 场景中没有时 | UI 模块释放时销毁（若是自动创建） |
| UiRoot | 没传根预制体时 | UI 模块释放时销毁 |
| Canvas 三层 | 随 UiRoot | SafeArea / Page / Popup / Toast |

- 自动创建的根与 EventSystem 会 `DontDestroyOnLoad`，切场景后仍可用；
- 场景已有 EventSystem 时复用，不重复创建；若它没有输入模块会给出警告；
- 需要自定义布局时，传自己的 `UiRoot` 预制体即可，框架不销毁传入对象。

## 6 打开与关闭 API

| API | 用途 |
|---|---|
| `GameEntry.OpenPanelAsync(id, args, ct)` | 按 Catalog ID 打开，args 原样传给 `UiView.OnOpenAsync` |
| `GameEntry.ClosePanelAsync(id, all, ct)` | 按 ID 关闭；默认最上层一个 |
| `GameEntry.UI.CloseAsync(handle, ct)` | 按句柄精确关闭 |
| `GameEntry.UI.CloseAsync(id, all, ct)` | 与 `ClosePanelAsync` 等价 |
| `GameEntry.UI.Navigation.PushAsync(key, args, ct)` | 页面入栈 |
| `GameEntry.UI.RequestBackAsync(ct)` | 返回键统一入口 |
| `GameEntry.ShutdownUIAsync()` | 关闭全部并释放 UI（Boot 会自动做） |

`args` 与 `ct`：

- `args` 为 `null` 时会替换成空对象；面板里 `args is MyArgs` 判断；
- `ct` 只保护"打开/关闭的等待过程"，取消不会留下半开面板；关闭流程本身会继续。

## 7 代码生成与绑定

菜单 **NowFrameWork → UI → Config** 配置生成器，右键面板 **生成 UI 绑定脚本**：

- 只生成带标记的节点：`[Button]primary`、`[Text]header`；
- 自动挂 `UiPanelDefinition` 与 View 脚本；
- 字段写入 `// <auto-generated>`，事件与生命周期写入独立区块，手写逻辑放 `// <user-code>`；
- 生成后用 `SerializedObject` 直接写入引用，运行时不查找组件。

详细规则见 [32 使用手册](32-NowFrameWork框架使用手册.md) 第 5 章。

## 8 输入注意事项

- 项目实际由 **Input System** 接管键盘；旧版 `Input.GetKeyDown` 可能收不到事件；
- 场景里只保留一个 EventSystem，并且只挂一个输入模块；
- `Active Input Handling` 改完必须重启编辑器；
- 返回键建议走框架 `InputModule`，不要直接轮询 `Input`。

## 9 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `UI 尚未启用` | BootFlow 没配 UiCatalog | 填 Catalog，或入口调用 `EnableUIAsync` |
| `未注册的界面` | 打开的是 Catalog 里没有的 ID | 收集面板定义 |
| 面板打开但点不了 | EventSystem 没有输入模块 | 添加 `InputSystemUIInputModule` |
| 弹窗被页面盖住 | `Layer` 填成 Page | 改为 Popup |
| 关闭没反应 | 没有关闭触发 | 按钮回调或调用 `ClosePanelAsync` |
| 切场景后 UI 丢失 | 根不是自动创建 | 使用 Boot 装配，或把自定义根设常驻 |
