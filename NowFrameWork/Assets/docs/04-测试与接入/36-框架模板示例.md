# 36 · 框架模板示例

模板把常用模块放进一个横屏场景。素材是简单的 UGUI、立方体、球、配置文本和仓库已有的短音频。场景可以作为新项目接入框架时的参考。

## 打开并运行

1. 选择 **NowFrameWork → Examples → Open Framework Template**，或双击 `Assets/Scenes/FrameworkTemplate.scene`。
2. 在 **Window → Asset Management → Addressables → Groups** 的 **Play Mode Script** 选择 **Use Asset Database**，点击 Play。此模式直接读取项目素材，仍经由 Boot 的 Addressables Provider 和框架的资源服务。
3. 方向键、手柄方向键或左摇杆移动焦点。Enter / A 确认，Esc / B 返回。鼠标也可以直接点击。Boot 的「取消 / 停止」会收尾整个示例，停止后可在同一场景启动。

如要验证真实包，在 Addressables 中执行 **Build → New Build → Default Build Script**，然后用 **Use Existing Build** 重新 Play。导出 Player 时把 `FrameworkTemplate.scene` 加为启动场景，并为目标平台构建 Addressables 内容。附加场景 `FrameworkTemplateFixture.scene` 由 Addressables 管理，保持在示例分组中即可。示例分组的 Build/Load Path 使用项目的 Local 路径。

## 按钮与可观察结果

| 界面 | 操作 | 观察点 |
|---|---|---|
| 首页 | **Module lab / Settings / Show toast** | 进入子页面、打开模态弹窗，或显示短提示。Toast 不接管当前控件焦点。 |
| Module lab | **Read config** | 同一份 Addressable 文本先由一次普通租约读取并归还，再交给 ConfigService 持有缓存。 |
| Module lab | **Rent / return cube** | 在右下方显示或归还一个立方体。再次租用时状态栏可看到复用的实例 ID。池保留自己的资源租约。 |
| Module lab | **Load / unload scene** | 右下方出现或移除一个来自附加场景的球，可在 Hierarchy 查看附加场景。 |
| Module lab | **Event + timer / Advance HFSM** | 事件订阅收到消息后退订，非缩放计时器约 0.25 秒后更新状态。HFSM 从 `Idle` 进入 `Running / First`，随后进入 `Running / Second`，退出再进入仍会恢复 `Second`。 |
| Module lab | **Dump resource leases / Hide / show page / Trim UI cache** | Console 输出租约明细，页面显隐保留同一会话，主动调用低内存清理路径只回收已关闭的缓存。先打开并关闭 Settings，缓存计数会从 1 降到 0。 |
| Settings | **English / 简体中文** | Unity Localization 切换样例文本。语言保存在独立设置文件，重新运行时恢复。 |
| Settings | **Start / stop BGM / Play two effects / Mute / restore volume** | 循环音乐、同 Clip 连发音效、音量即时应用并保存。 |
| Settings | **Switch Pulse key P / O / Check conflict with I** | 保存普通动作的键位覆盖。关闭弹窗后，按当前键或手柄 X，计数增长。弹窗期间普通动作被屏蔽。I 与同一 Action Map 的 Other 冲突，演示查询结果。 |

示例的语言与演示设置文件位于 `Application.persistentDataPath/FrameworkTemplate`。发行、HybridCLR、交互式复合改键和 DOTween 的接入仍可参考已有的专项样例及文档。[Windows 资源发布](../06-模块API/18-Windows资源发布与恢复.md) · [输入 API](../06-模块API/16-输入与返回导航.md) · [DOTween 接入](30-UI面板动画与DOTween接入.md)

## UI 层级

```text
Framework Template                 BootFlow、FrameworkTemplateEntry、设备监听
├── Demo Camera                    AudioListener
├── EventSystem                    InputSystemUIInputModule
└── UiRoot                         运行时由 UiModule 生成
    ├── SafeArea                   UiRoot 安全区参考节点
    ├── Page                       首页、Module lab，由页面栈控制
    │   └── Home / Modules        UiView、Canvas、CanvasGroup、GraphicRaycaster
    │       └── SafeArea / Layout
    │           ├── Header         标题与说明
    │           ├── Actions        Button 与显式上下导航
    │           └── Status Card    当前操作及模块状态
    ├── Popup                      共享模态遮罩、Settings
    │   └── Settings / SafeArea / Dialog
    │       ├── Header
    │       ├── Actions
    │       └── Status Card        含订阅语言表的本地化文本
    └── Toast                      无射线组件，仅展示消息
```

- `TemplateContent.Definitions()` 声明面板 ID、地址、层级、遮罩与缓存规则。页面用 `Navigation.PushAsync` 入栈，普通弹窗和 Toast 使用 `OpenAsync`，手上的 `UiHandle` 代表一次会话。
- `TemplatePanel` 在 `OnCreate` 注册一次按钮监听，用 `OnOpenAsync` 接收当前会话命令，按显示顺序配置原生上下导航。按钮使用 `VisibleToken` 阻止已隐藏的视图发起命令，入口用自身生命周期令牌继续管理已开始的切页操作。关闭时清掉参数，销毁时解除监听，缓存复用时不会重复注册。
- `TemplateToast` 只呈现文本。入口检查打开结果并持有句柄，停留一段时间后在 `finally` 关闭。
- `EventSystem` 负责移动和确认，`InputModule` 统一处理 Esc / B。普通动作由独立的 Input Action Map 驱动，并用命名门控响应模态弹窗。

## 资源归属与代码位置

| 所有者 | 示例 | 释放 |
|---|---|---|
| `FrameworkTemplateEntry` | 初始化 UI、输入、项目服务入口以及持久化设置 | 停止接收命令并等待在途操作退出，再依次关闭各自拥有的资源 |
| `TemplateResourceDemo` | 直接资源租约、立方体池、附加场景、事件、计时器和 HFSM | 归还独立租约，先销毁池实例再释放池，等待附加场景卸载 |
| `UiModule` | 由地址加载的面板实例 | 关闭后按定义销毁或缓存，停止模块时清理 |
| `BootSession` | Addressables Provider 背后的资源服务、音频模块、配置缓存与 App | 等待项目入口退出，清理 Boot 自己的服务并核对未归还的租约 |

运行时代码和示例 Prefab 位于 `Assets/Game/FrameworkTemplate`。场景引用 `UiRoot` 作为 UI 基础设施，面板、配置、立方体和附加场景通过 `FrameworkTemplate/` 地址读取。音频沿用 `audio/bgm` 和 `audio/sfx`，语言表复用仓库已有的 Localization 数据。编辑器生成器 `FrameworkTemplateMenu` 保存了节点、布局和 Addressables 登记的搭建过程，现成场景和 Prefab 可直接在 Inspector 查看。

## 编辑器常见问题

### 双击脚本后 Visual Studio 只显示解决方案

在团结 Hub 打开主工程的 `NowFrameWork` 目录。先前通过回归工具打开的工程可能位于 `Build/UiInputIsolated-*/NowFrameWork`，其中的脚本是测试时的副本。可先在 Visual Studio 按 `Ctrl+O`，打开主工程下的 [FrameworkTemplateEntry.cs](../../Game/FrameworkTemplate/FrameworkTemplateEntry.cs) 确认源码和中文注释。

如果双击仍只打开解决方案，在团结的 **Edit → Preferences → External Tools** 中重新选择 **External Script Editor**。本机同时安装了 Visual Studio 2019 和 2022，可选用 **Visual Studio 2022**，点击 **Regenerate project files** 后再打开脚本。

### Console 报文档的 .meta 没有有效 GUID

如果日志指向 `36-框架模板示例.md.meta`，影响范围是这份 Markdown 文档的资产导入。场景和 Addressables 不引用该文档。本次将此前误写的 33 位 GUID 修正为 32 位十六进制 GUID，主工程导入日志已确认成功。清空 Console 后用 **Assets → Refresh**（`Ctrl+R`）可以复查。
